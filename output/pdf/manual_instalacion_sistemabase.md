# Manual breve de instalación de SistemaBase

Este documento resume los pasos para instalar SistemaBase versión 1.5 en una computadora con SQL Server disponible.

## 1. Seleccionar la instancia de SQL Server

Al iniciar el instalador, se muestra la pantalla de selección de instancia de SQL Server. En esta pantalla se debe elegir la instancia detectada en la computadora donde se va a instalar el sistema.

Si la instancia aparece en la lista, seleccionarla y continuar con el botón Siguiente. Si no aparece, escribir manualmente el nombre exacto del servidor SQL Server, por ejemplo el nombre del equipo o el nombre de la instancia correspondiente.

## 2. Seleccionar las tareas adicionales

Luego, el instalador permite elegir tareas adicionales. En esta pantalla se puede marcar la opción Crear un acceso directo en el escritorio para abrir el sistema más fácilmente después de la instalación.

Una vez seleccionada la opción deseada, presionar Siguiente para continuar.

## 3. Finalizar la instalación

Cuando el instalador informa que la instalación fue completada, se puede dejar marcada la opción Ejecutar SistemaBase para abrir el programa al finalizar.

Por último, presionar Finalizar. Si se dejó marcada la opción de ejecución, el sistema se abrirá automáticamente.
